# Content Factory downloads

Windows installers and update packages for Content Factory.

Download the latest Setup.exe from [Releases](https://github.com/StephenBergman/content-factory-releases/releases/latest). After the first installation, open **App updates** inside Content Factory for future versions.

The installer preserves your project library and provider settings. Source code is maintained in a separate private repository. No API keys, project media, or user settings are included here.
